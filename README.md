# GeddesWorks Hub

This repository now hosts the React + TypeScript version of `www.geddesworks.com`.

## Stack

- Vite
- React 19
- TypeScript
- MUI
- Tailwind CSS
- GitHub Actions for build and `gh-pages` deploys

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

Project and link content lives in `src/data/siteContent.ts`, so adding newer projects should mostly be a data update instead of another layout rewrite.
